# LangChain Agent层与研究循环重构

用户确认范围：完整迁移因子挖掘、策略研究、市场扫描的模型调用、角色交接及研究循环。保留数值计算、回测、数据库和交易执行。

输入：研究合同、创意/行情事实及已有证据 → LangChain角色调用和严格解析、LangGraph条件编排 → 原有研究记录、评估、准入与停止结果。

## 实施步骤

1. 共用LangChain消息链与严格输出解析；MiMo继续ChatOpenAI，Codex订阅和固定回放作为受控传输适配器接入同一链。
2. 因子A流程迁移为构想→逐候选计算→评估→优化→继续或完成；证据分页及回复纠正也由图分支控制。
3. 策略迁移为设计→能力/数据检查→语义审核→回测→评估→决策；语义修正、优化、保留和停止均显式分支。
4. Goal按现有阶段图调度选择、等待、探索、冻结、验证和成果登记；保留运行锁、只追加检查点及B一次读取规则。扫描使用同一调用链，格式纠正作为图循环。
5. 原流程回归、LangChain传输测试、固定回复端到端验收、真实小模型调用与实际图拓扑检查；核对修改范围与输出证据。

## 必须保持

- 合同、研究门槛、时间/数据边界、计算与回测公式不变。
- 角色仍只能请求原有受控证据读取；不开放任意Python、shell或交易工具。
- 格式纠正最多3次；传输重试由现有SDK规则处理；不引入空报告降级。
- 现有证据文件是恢复依据，不建立第二套独立的数据库检查点。LangGraph控制本次执行，恢复仍校验原始记录、代码与数据。
- 自然研究循环不因LangGraph默认步数限制而提前结束。
- 不修改旧运行指纹、不重写旧数据或历史结果。新流程用新目录验收。
