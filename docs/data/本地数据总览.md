## 5. 原始数据怎样成为研究输入

当前主流程是：**原始行情／事件 → 统一币种和单位 → 按小时信号时间读取 → 生成因子字段与公式结果。**

- 价格、成交量、主动买入量来自已经结束的小时K线。
- 持仓和多空比例取小时信号时点之前的最近快照，不是小时均值；5分钟指标过期后不继续沿用。
- 资金费率按真实结算事件读取。24小时、7日累计值由窗口内结算事件计算，不能把向前沿用的小时值重复相加。
- 现货与带倍率的永续价格、基础币数量先统一口径。USDT成交额、比例和费率不随倍率缩放。
- 清算按事件小时归属；有接收时间时还要检查是否晚到。没有文件、确认无事件、来源不明是不同状态，不能统一填0。

由这些字段可计算收益率、波动率、成交额变化、主动买入占比、现货与永续价差、资金费累计、OI变化等研究变量。这些是计算结果，不是额外下载的独立数据源。

**OI只有当前未平仓总量和总名义价值，不提供历史开仓成本、持仓者浮动盈亏或完整多空仓位分布。** 五分钟指标中的 `taker_long_short_volume_ratio` 及其派生 `taker_flow_net` 因历史时间／数量口径尚未统一，仍不进入公式白名单；小时K线的主动买入成交额字段可以使用。
