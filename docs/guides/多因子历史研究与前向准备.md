# 多因子历史研究与前向准备

本轮使用独立恢复的 Binance 官方价格和资金费率归档。原有数据库、历史工程结果和上游因子卡不改写。

## 数据口径

研究队列为 BTC、ETH、SOL、BNB、XRP、ADA、AVAX、DOGE、DOT、LINK；不是已验证的历史动态选币规则。数据保留原始 ZIP、文件签名和行来源。原始现货缺口及短小时线保留为缺失因子输入，永续成交价和标记价格要求完整可执行网格。

按用户确认，资金费结算标记价使用事件之前最后一根完整原始分钟标记价的 close 估算，最大年龄 60 秒。它是明确的成本代理，不是交易所原始结算价。原始发布及接收延迟也未认证。

## 历史运行

冻结合同位于 `examples/strategy_research/multifactor/historical/contract.json`。A+B 为 UTC `[2022-08-01,2025-08-01)`，C 为 `[2025-08-01,2026-08-01)`。既往数据用途保留；C 用于内部验证，最终观察需要冻结后新产生的行情。

```sh
.venv/bin/python -m crypto_quant.cli strategy-research historical-run \
  --contract examples/strategy_research/multifactor/historical/contract.json \
  --provider codex --model gpt-6-luna --reasoning-effort max \
  --codex-bin '/Applications/ChatGPT.app/Contents/Resources/codex-cli/CodexCLI.app/Contents/MacOS/codex' \
  --timeout-seconds 300
```

源清单必须完成核验；命令不会回退到原主库。运行编号对应的目录已存在时拒绝覆盖。

每臂最多两项新组合实验，模型调用最多五次。Agent 只收到全池和单因子初始证据及自身逐轮结果；已计算的移除因子结果与固定臂新结果封存。当前四卡池允许未测的两卡组合。全池等权是共享基准，也参加候选选择；既有单因子和移除因子结果不参与额外候选搜索。

选择先按预定 A+B 净收益排序，再按较低回撤、卡片 ID 处理平局。选择记录在加载 C 行情面板及计算账户表现之前保存。完整数据来源校验和固定币池网格核验会预先覆盖 C 的文件签名及成员元数据；这些校验不产生 C 收益或向 Agent 提供 C 结果。C 只评估该冻结候选、等权参考和候选成本压力，结果不会回传同一轮 Agent 改方案。

进入条件预先固定：A+B 与 C 的净收益和两倍成本收益均不低于零，最大回撤不超过 15%，至少一个有成交的调仓时点。最高排名候选未过条件时保留 C 诊断并报告 `no_candidate_passed`，不自动转选其他候选或启动账户。

2026-10-02 的完整运行已结束：GPT-6 Luna（max）实际调用五次，每臂各完成两个新实验。五个候选均未通过 A+B 门槛。按规则冻结的 F3＋F4 在 A+B 净收益为 −63.47%、最大回撤 68.65%，C 净收益为 −20.03%、最大回撤 25.15%；两倍成本收益也均为负。状态为 `no_candidate_passed`，前向账户未启动。完整结果见 [历史研究报告](/Users/stellan/量化投资/experiments/strategy_research/historical_20261002/runs/multifactor-history-20261002/report.md)。

## 前向接口

`multifactor_forward.freeze_forward_candidate` 接收已合格的历史结果文件及新鲜种子数据；程序核验 A+B/C 资格、规则、卡片、来源和结果文件的对应关系。调用方自行填写 `qualified=true` 无效。

准备只创建本地冻结包；实际启动单独执行。种子截至启动前最后已收到的完整小时；新收盘信息到达后冻结订单数量，随后使用首个实际可见报价模拟成交。每笔行情、资金费及报价保存发生、可用和接收时间。重复事件不会重复记账，冲突重复或不能应用的晚到事件会停止并留证据。重启从事件记录恢复。

观察合同为 30 天、至少 20 次调仓，回撤停止线 15%。离线事件回放验证接口和账本，不标记为真实前向观察；行情采集和账户启动状态以实际记录为准。
