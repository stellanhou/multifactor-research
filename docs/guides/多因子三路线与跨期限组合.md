# 多因子三路线与跨期限组合

本研究在已有调仓与永续账户实现上，比较期限内的因子选择、加权方法，以及期限之间的目标持仓组合。三个预测期限分别为 1h、4h、24h；模型更新、信号计算和实际交易是独立的时间安排。

## 期限内比较

| 方法 | 作用 |
|---|---|
| 全池等权 | 固定基准 |
| 滚动 ICIR | 延续已有动态加权基准 |
| 相关性聚类、分组等权 | 控制相似因子重复表达的信息 |
| Ridge | 联合估计并收缩因子权重 |
| Elastic Net | 联合估计、收缩并产生稀疏权重 |
| 有限容量池、增量评价 | 在固定搜索预算内挑选具有组合增量的因子 |

三条新路线中的正则化路线包括 Ridge、Elastic Net 两种方法，连同两个基准共六组。首轮不叠加正交化。每组同时使用原定时调仓 R0 和双缓冲 R4；R4 沿用两多两空、入场前后两名、持有前后四名和 2 个百分点仓位缓冲。

所有方法读取相同的标准化因子面板、有效币种和小时网格。共同数据不足时没有信号；某个方法主动不分配因子时，该方法单独空仓，不抹去其他方法的结果。报告保留空仓时段，不能仅挑有交易的时段比较。

## 训练时间与历史用途

信号时间戳标记小时开盘，因子使用该小时完成后的数据；交易发生在下一小时开盘。期限为 h 的训练标签从 t+1 的开盘到 t+h+1 的开盘。拟合只使用终点不晚于拟合时间的标签。

聚类使用过去窗口中同一时点的因子截面相关性，以绝对相关性超过阈值的连接构造分组；这是相关图连通分组。组内按历史相关关系对齐相反方向，再组内等权、组间等权。回归和增量筛选使用按时间划分的内部训练、验证，并排除跨过内部验证起点的训练标签。参数选择后，用已成熟的历史训练样本重新拟合，再产生后续预测。参数网格、因子池容量和搜索次数均写入合同。

首轮模型窗口为 90 天，至少 720 个内部训练小时，内部验证窗口 21 天、至少 168 个有效小时，每 168 小时更新聚类、回归和因子池。ICIR 沿用每小时更新、30 天窗口和至少 168 个有效 IC。聚类相关窗口 30 天、阈值 0.8。回归用训练标签均方根归一化后的目标，正则化强度固定比较 `0.00001 / 0.001 / 0.1 / 10`，Elastic Net 的 L1 比例为 0.5。有限池容量 8，每次更新最多依次评价 32 个候选加入提案，以内部验证 R² 的正增量决定是否加入。这些参数是首轮实验设定，未据结果调优。

开发段和 C 段接续模型历史，重叠因子保留先前开发段的值；行情重叠部分必须一致。每个阶段的独立账户仍按原合同从初始本金开始。已有因子卡的发现、方向和准入使用过历史数据，因此滚动拟合只说明新增算法遵守时间顺序，不把整个因子发现过程重新认定为独立样本外研究。C 段已暴露，仍用于内部历史比较。

## 跨期限组合

同一种因子组合方法、同一种调仓规则产生三套期限子组合，再比较固定等预算与带历史均值门槛的协方差风险预算。后者使用最近 720 小时、至少 168 个历史观测，只分配给历史平均净收益为正的期限，对协方差做固定 10% 对角收缩后求等风险贡献；没有满足条件的期限时空仓。该对照同时改变风险分配和期限准入，不能将全部差异单独归因于协方差。

外层只读取此前已实现的子组合收益，不能读取内层模型的拟合收益或未来收益。账本收益保留实际收盘时间；信号标签为 t 时，只使用实际收盘时间严格早于 t 的记录。这是有意采用的保守信息滞后，不把账本收益向原始下单信号时间回移。

合成目标按币种净额相加，受同一总敞口和单币上限约束，然后进入一个总账户。总账户直接接收连续目标仓位，不再重新排名选两多两空；其持仓数量可以超过四个。仓位缓冲使用总账户自己的实际数量、净值和价格，最终费用按净额订单计算。子账户用于产生目标与历史风险信息，其手续费不再次从总账户扣除。

基础成本和两倍成本各自执行完整决策。总敞口、单币上限指决策时价格和交易前净值；成交成本和之后的价格变化可能造成实际比例漂移。

## 运行与交付

依赖已在 `pyproject.toml` 与 `uv.lock` 锁定。Elastic Net 保持[标准的 L1＋L2 损失函数](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.ElasticNet.html)，通过增广训练矩阵转换为等价的 Lasso 问题，固定使用 scikit-learn 的坐标下降求解器，以处理本因子面板的共线性。坐标更新顺序使用固定随机种子 0；以对偶间隙检验收敛，容差为 `1e-8`，最多 500 万次迭代。不收敛会终止当前运行，不跳过参数或更换算法。解析解和原始目标的最优性条件另有回归测试。新环境先安装锁定依赖：

```sh
uv sync --locked --inexact --extra dev
```

```sh
.venv/bin/python -m crypto_quant.cli strategy-research selection-run \
  --contract examples/strategy_research/multifactor/pool/selection.contract.json \
  --output experiments/strategy_research/selection_20261003
```

入口使用独立运行目录，拒绝覆盖同名运行。合同和计划先冻结，随后产生模型记录、信号与账户结果。算法和历史计算不调用语言模型。

查看结果时同时比较净收益、夏普、回撤、换手、费用、实际敞口、分月份表现和两倍成本结果。各方法按冻结合同全部运行，不按 C 段最高收益重新选组。工程测试和短区间联调用于验证实现；完整历史比较必须以独立运行产生的报告为准。

## 前向—后向选择与净夏普对照

新增 `stepwise` 和 `stepwise_net_sharpe` 两份独立实验，保留原六方法和 `pool` 算法。每周从空池开始：完整比较所有剩余因子的加入提案，取目标增量最大的一个；每次加入后，完整比较所有已选因子的删除提案，反复接受最佳正增量删除；随后重新考察所有未入选因子。容量仍为 8，接受增量仍须大于 `1e-6`。每次拟合的提案上限为 2,048，每个子集重选四个 Ridge alpha；预算不足以完成整轮时，在上一完整轮停止。缓存复用子集评分，命中缓存仍计入提案预算。每轮完整候选、分数、alpha、增量、动作和停止原因均保存。

`stepwise` 使用原内部验证 R²。`stepwise_net_sharpe` 使用同一 21 天源信号窗口的 R0 组合净夏普，alpha 同样按净夏普选择。每个验证账户从原本金、空仓开始，调仓相位固定为开发段账户起点前一小时；验证信号只到已成熟的末源时点，最后可执行的 R0 持仓延续到拟合时点。账户包含手续费、成交价滑点及实际资金费收支，最后行情收盘不晚于拟合时点，资金费时点严格早于拟合时点。净夏普按小时简单收益、样本标准差和一年 8,760 小时计算，无风险收益为零。完成前向—后向选择后，仅最终子集及所选 alpha 的验证净收益大于零且发生交易，才产生后续信号；未通过时空仓，不另选子集或 alpha。

两组的共同就绪时间、因子完整性掩码、成熟标签、训练与验证隔离、30 币生命周期和最终账户规则一致。各组运行 40 个账户：三个期限的 R0/R4，以及固定等预算和均值门控风险预算的 R0/R4，均覆盖开发段、后一年、基准及两倍成本。净夏普内部优化 R0，最终同时报告 R0 与 R4。21 天内的夏普可能受少数交易影响；两组使用已观察历史作探索性比较。原 `pool` 的预算为 32，因此与新 R² 路线的差异同时包含搜索方式和预算变化。

```sh
  --contract experiments/strategy_research/stepwise_net_sharpe30_20261003/selection.contract.json
```

## 连续仓位构建（2026-10-04）

`multifactor_portfolio.py` 在既有账户引擎之前构建连续目标，保留原两多两空排名规则。新增三种可直接调用的构建方式：

| 接口 | 本轮固定规则 |
|---|---|
| `generate_tapered_targets` | 多空各前五名，两侧各40%，按5∶4∶3∶2∶1分配，即每侧13.33%、10.67%、8%、5.33%、2.67%；单币上限20%。币种不足时两侧取相同席位数，缺少的外侧席位留现金。 |
| `generate_score_weighted_targets` | 综合分数截面去均值，正负两侧按分数绝对值比例分配，触及单币20%上限的剩余预算向同侧其余币分配。两侧预算相等且不超过40%；某侧容量不足则两侧同时缩小，全同分时空仓。 |
| `smooth_target_weights` | 初始空仓，递推 `新目标 = 0.5 × 上次平滑目标 + 0.5 × 本次原目标`。普通排名退出渐减；当前资格失效立即归零并清除历史。模型要求空仓时将整行资格设为false，立即退出。平滑后不重新放大到80%。 |

输入是调仓决策时点的分数或目标表，输出直接交给 `run_perpetual_account`，不再重新投影为前二/后二。EMA平滑的是目标权重，实际下单仍由账户自己的持仓数量、净值及信号收盘价计算；基础与两倍成本账户独立记账。

下面的配对入口固定已有90天组合研究中的六条E3模型路线，分别比较原版、梯形、原版目标EMA和连续分数权重。保持每日调仓，开发段与C段、基础与两倍成本共96个账户；不重新搜索因子或调整参数。输出目录必须尚不存在。

```sh
.venv/bin/python scripts/multifactor_position_validation.py \
  --source-run experiments/strategy_research/combination90_20261003/run3 \
  --output experiments/strategy_research/continuous_positions_20261004/fixed_models_v1
```

入口先保存规则和源码快照，逐个核对原版目标与账本，独立验算全部新账户并检查运行前后输入哈希。比较表同时提供净夏普、收益、回撤、换手、费用、总敞口、净敞口和持仓宽度。EMA可能因反向目标抵消而降低总敞口；分数归一化在截面分散程度很小时也可能放大微小分数差异，应结合这些指标判断结果。C段继续作为已暴露历史评价，不据此改选冠军。

方法背景可参考 [Boyd 等的多期组合构建框架](https://web.stanford.edu/~boyd/papers/cvx_portfolio.html)：同时权衡预期收益、风险、交易成本和持有成本。本轮只对照上述固定仓位规则，不将其表述为该优化框架的实现。


本轮固定模型对照已完成：46项相关测试通过，96/96个账户独立对账通过，24个原版账户的最大净值复现误差为0。以净夏普为绩效比较指标，目标EMA在开发段和C段均改善6/6条路线；梯形两段均为0/6；连续分数权重分别为0/6和3/6。C段换手降幅分别为EMA 47.4%～49.5%、梯形6.6%～9.6%、分数权重25.3%～29.4%。EMA的平均总敞口同时下降1.93～4.03个百分点；按平均敞口归一的交易强度仍下降45.0%～46.8%，这个诊断不等于完全匹配风险的因果对照。全部开发段基础成本账户及全部两倍成本账户仍亏损，没有配置通过原开发段准入门槛。
